# Ron-1

رون-1 مساعد لغوي يعمل محليًا داخل المتصفح باستخدام **SmolLM2-135M-Instruct Q4F16**. المستودع هو مصدر كود الواجهة ومحرك التشغيل وإعدادات النموذج، وتُجهَّز أوزان النموذج كأصول ضمن حزمة النشر على GitHub Pages.

## تجربة المحادثة

افتح [Ron-1 على GitHub Pages](https://arkanws513-spec.github.io/Ron-1/). يبدأ تشغيل النواة تلقائيًا، ثم يمكنك إرسال الرسائل بعد ظهور حالة «العقل جاهز». لا تحتاج إلى الضغط على زر تشغيل في الاستخدام الطبيعي.

## التشغيل المحلي والاستضافة

- `index.html`: واجهة الدردشة، وبدء التشغيل التلقائي، وحفظ سجل المحادثة محليًا.
- `ron-model-worker.js`: تحميل SmolLM2 وتوليد الردود داخل Web Worker باستخدام ONNX Runtime Web/WASM.
- `sw.js`: تخزين ملفات التشغيل والبيانات والأجزاء الثنائية للأوزان في Cache Storage على الجهاز عند تنزيلها بنجاح.
- `vendor/transformers/`: مكتبة Transformers.js وملفات WASM.
- `models/` و`models-v2/`: إعدادات النموذج والمفردات والبيانات الوصفية.
- `weights/ron1-q4f16-*.bin`: أجزاء أوزان النموذج، تُدرج في حزمة نشر الموقع بواسطة GitHub Actions.

الأوزان الكاملة نحو 117 ميجابايت، ومقسمة إلى ثلاثة أجزاء لتسهيل الاستضافة والتنزيل. ليست مضمنة داخل ملف JavaScript واحد؛ لكنها تُنسخ إلى مخرجات نشر Ron-1 وتُخدم من نفس أصل الموقع. لا يحتاج المتصفح إلى الاتصال بـ Hugging Face أو GitHub Releases أو خادم استدلال خارجي أثناء التشغيل. يحتاج الإعداد الأول إلى اتصال لتنزيل الملفات. بعد تنزيلها وتخزينها بنجاح، يحاول Service Worker إعادة استخدامها دون اتصال؛ وقد يمنع نقص مساحة الجهاز تخزين بعض الملفات.

## توافق الاستدلال

إذا ظهر تعارض معروف بين أنواع بيانات float16 وfloat32 أثناء التوليد، يجرب رون مسار توافق احتياطيًا يعطّل KV cache لهذه المحاولة. هذا المسار أبطأ ويستخدم حدًا أقصر للتوليد، ولا يُعد نجاحه مضمونًا على كل جهاز أو إصدار متصفح. اختبارات CI تتحقق من عقد التشغيل والملفات، لكنها لا تستبدل اختبارًا فعليًا لتوليد رد على جهاز Android.

## التدريب والتطوير

النموذج المضمّن حاليًا هو نموذج جاهز صغير، وليس نموذجًا دُرّب من الصفر داخل رون. أوزان ONNX المكمّمة المستخدمة في المتصفح مخصصة للاستدلال وليست مسار التدريب نفسه. أي تدريب لاحق يحتاج مسارًا منفصلًا على أوزان قابلة للتدريب (مثل LoRA/PEFT)، ثم تقييم النموذج وتصديره إلى صيغة ONNX مناسبة وإعادة التحقق من التوافق والحجم قبل نشره.

## الفحوصات

يشغّل GitHub Actions فحوصات بنية ملفات النموذج، وأحجام أجزاء الأوزان، وتوقعات بدء التشغيل، ومسار التوافق الاحتياطي، ونشر Service Worker. اجتياز هذه الفحوصات لا يعني أن كل متصفح مدعوم؛ يجب رصد أخطاء التشغيل الواقعية قبل اعتماد أي تغيير متعلق بأنواع بيانات ONNX.
