# Ron-1

رون-1 تجربة مساعد لغوي يعمل محليًا داخل متصفح المستخدم باستخدام نموذج مفتوح الأوزان صغير. مستودع GitHub هو المصدر الأساسي للكود، وGitHub Pages ينشر الواجهة الثابتة.

## تشغيل رون

افتح https://arkanws513-spec.github.io/Ron-1/ من متصفح حديث، واضغط **تحميل العقل**، ثم انتظر اكتمال تحميل ملفات النموذج. بعد التحميل تُولَّد الردود على الجهاز داخل المتصفح؛ لا يُرسل نص المحادثة إلى خادم استدلال تابع لرون.

## النموذج الحالي

- النموذج: [SmolLM2-135M-Instruct ONNX](https://huggingface.co/onnx-community/SmolLM2-135M-Instruct-ONNX).
- مسار التشغيل الحالي: WASM عبر معالج الجهاز، لتجنّب الاعتماد على WebGPU الذي فشل على بعض الأجهزة.
- حجم ملف الأوزان التقريبي في صيغة Q4: 181 ميجابايت؛ وقد تُحمّل ملفات tokenizer وتهيئة إضافية. قد يتطلب التحميل الأول بيانات إنترنت وذاكرة متاحة.
- النموذج الصغير محدود القدرة، وقد تكون إجاباته العربية أو استمرارية الحوار غير مثالية. هذا النموذج ليس تدريبًا من الصفر ولا يعني أن رون أصبح نموذجًا مستقلًا مدرّبًا بالكامل.

## الاستقلال والخصوصية

لا يحتوي مسار التشغيل الأساسي على API مدفوع أو مفتاح خدمة أو خادم استدلال خارجي. يحتاج تنزيل النموذج لأول مرة إلى الاتصال بمستودع النموذج وملفات مكتبة Transformers.js على CDN. بعد التحميل قد يعيد المتصفح استخدام الملفات المخزنة مؤقتًا، حسب إعداداته ومساحة التخزين.

## النشر والتطوير

- الواجهة: index.html
- تشغيل النموذج داخل Worker: ron-model-worker.js
- النشر: .github/workflows/pages.yml
- التحقق الأساسي: .github/workflows/ci.yml

GitHub Pages تستضيف ملفات الموقع الثابتة فقط؛ تشغيل الاستدلال يتم في متصفح المستخدم وليس على خادم GitHub. لا توجد خدمة استضافة مدفوعة أو استدلال مدفوع مفعّل ضمن هذا التصميم.

## الاختبار

نجاح حفظ الملفات في GitHub لا يثبت وحده أن النموذج يعمل على كل هاتف. يجب التحقق من تحميله وتوليد أول رد على الجهاز المستهدف. إذا ظهرت صفحة بيضاء أو خطأ ذاكرة، لا تكرر تنزيل النموذج مباشرة؛ سجّل نص الخطأ أولًا.
